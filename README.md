\# ⚡ DevOps AI Assistant Platform



An end-to-end, 100% private Local AI platform powered by \*\*Qwen 2.5 Coder\*\* and \*\*FastAPI + Streamlit\*\*. Analyze any GitHub repository for Architecture Flowcharts, OWASP Security Audits, Codebase RAG Q\&A, Automated Documentation, Cloud Cost Optimization, and DevOps/CI-CD Manifests.



\---



\## 🌟 Key Features



\- \*\*🏗️ Architecture Breakdown \& Flowchart\*\*: Visual interactive Mermaid.js diagrams \& stack breakdown.

\- \*\*🛡️ SAST Security Audit\*\*: OWASP Top 10 vulnerability detection \& secure code refactoring.

\- \*\*💬 Codebase Chat (RAG)\*\*: Ask direct logic/bug questions using TF-IDF code vector retrieval.

\- \*\*📄 Auto README Generator\*\*: Auto-draft production-ready `README.md` documentation.

\- \*\*☁️ Cloud \& Cost Optimizer\*\*: AWS/GCP/Vercel hosting strategy \& monthly cost reduction rules.

\- \*\*⚙️ DevOps \& CI/CD Generator\*\*: Auto-generate `Dockerfile`, `docker-compose.yml`, K8s manifests \& GitHub Actions pipelines.



\---



\## 🛠️ Prerequisites



Before running the app, ensure you have:

1\. \*\*Python 3.10+\*\* installed.

2\. \*\*Git\*\* installed on your machine.

3\. \*\*Ollama\*\* installed and running locally.
